# Teh Jie Yee | Petroleum Engineering Portfolio

Live site: https://dumplinggg0905.github.io

Static site (HTML, CSS, JS; no build step).

- Projects live in `main.js` in the `PROJECTS` array, listed in priority order within each group.
- Groups (Wells & offshore, Field technology concepts, Subsurface analysis, People) are defined in `GROUPS`.
- Each project has a one-line `result`, a `role` (what I personally did), a `context` (event and team size), an optional `key` number and `award`, and the detail shown when expanded.
- Images are in `assets/img/`.
